# CLAUDE.md

## Idioma del código

Todo el código va en inglés, incluidos los comentarios:

- Nombres de variables, funciones, clases y archivos
- Clases CSS y variables CSS (custom properties)
- Nombres de los custom elements (`am-tape`, `am-segment`, `am-quoter`)
- Endpoints de la API, claves de la base de datos e ids de las prendas
- Mensajes de error internos, nombres de las pruebas y pasos de los workflows

El texto que ve el cliente se queda en español: textos de la interfaz, la
plantilla del mensaje de WhatsApp y correo, los nombres de las prendas y los
tipos de dotación en `database/catalog.json`, y `lang="es"` en `index.html`.
El README también está en español.

Glosario usado al traducir: cinta → tape, tramo → segment, portada → cover,
cotizador → quoter, prenda → garment, talla → size, bordado → embroidery,
tarifa → rate, tramos de descuento → tiers, pedido → order.
